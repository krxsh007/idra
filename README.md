# IDRA — Intelligent Disaster Response Assistant

> **RESEARCH PROTOTYPE DISCLAIMER:** IDRA is an academic and research decision-support prototype for the Chennai Metropolitan Area (`STUDY_AREA_BBOX = [80.15, 12.95, 80.30, 13.15]`). Do **NOT** use for live life-safety dispatch. In a real emergency, dial **1070 / 1913 (State/GCC Control Room)**, **108 (Ambulance)**, or **112 (National Emergency Number)**.

---

## Overview
**IDRA** is a full-stack, multi-agent geospatial emergency response and coordination system combining:
1. **Two-Tier 7-Agent Orchestration (`api/app/agents/`):**
   - **Tier A (LLM-Assisted with Grounding & Deterministic Fallback):** `DisasterAssessmentAgent`, `RescuePlanningAgent` (Haversine DBSCAN $\epsilon=500\text{ m}$), `SynthesisAgent`, and `CitizenAssistantAgent`.
   - **Tier B (100% Deterministic — Zero LLM Dependency):** `FacilityRecommendationAgent`, `RoutingAgent`, and `ResourceAllocationAgent`, reconciled by a deterministic `ConflictResolver`.
2. **Hybrid RAG over Official SOPs (`api/app/rag/`):**
   - Combines 384-dimensional dense vector similarity (`0.70`) and lexical BM25 overlap (`0.30`) over NDMA Urban Flood Guidelines, Sphere Handbook Minimum Standards, and TNSDMA Chennai Flood SOPs (`data/kb/raw/`), enforcing a strict `RAG_SCORE_FLOOR = 0.35`.
3. **Hazard-Avoiding Dijkstra Router (`api/app/gis/`):**
   - Operates over a pre-built Chennai OpenStreetMap road network (`1,748` nodes, `6,820` edges in `artifacts/road_graph.pkl`) with PostGIS polygon intersection (`ST_Intersects`) and explicit reporting of unreachable destinations when a location is fully enclosed.
4. **Human-in-the-Loop Verification Gate:**
   - Every AI-generated recommendation enters the database as `PENDING` with `is_committed = False`. Only an authenticated `ADMIN` can verify, override, or reject recommendations and commit resource allocations.
5. **Tactical Command Center & Citizen Assistant (`web/`):**
   - Vite + React 18 + MapLibre GL JS dark tactical dashboard: hazard/report/facility map layers, live run timeline, prioritised briefing with origin badges and `REAL` vs `SIMULATED` provenance tags, and a Citizen Emergency Assistant chat drawer with urgent-escalation detection.

## Quickstart

### 1. Start Infrastructure & Run Migrations
```bash
make up
make migrate
make seed
```

### 2. Run Quality Gate & Evaluation Harness
```bash
make lint
make mypy
make test
make eval
```

### 3. Offline Mode vs. Gemini
`.env` ships with `LLM_BACKEND=fake`: embeddings are hashed and the Disaster Assessment agent uses a rule-based fallback, so the whole pipeline runs with no API key. For real LLM prose and MiniLM embeddings set `LLM_BACKEND=gemini` plus `GEMINI_API_KEY`, then re-run `make seed` (re-ingests the KB) and `docker compose up -d --force-recreate api`.

### 4. Default Seeded Credentials
| Role | Email | Password |
|---|---|---|
| `ADMIN` | `admin@example.com` | `SEED_ADMIN_PASSWORD` from `.env` |
| `RESPONDER` | `responder1@example.com` | `responder_password_1` |
